# Ejercicios del modelo de caja

Abre cada ejercicio con Live Server y consulta su README.

1. [Señales de tráfico](01-senal-pueblo/README.md): completa las propiedades CSS de tres señales dentro de `<style>`.
2. [Cupón de descuento](02-cupon-descuento/README.md): escribe todas las reglas CSS dentro de `<style>` para reproducir el diseño. El HTML y la imagen están preparados.
3. [Banner de anuncio](03-banner-anuncio/README.md): enlaza el archivo CSS externo de un anuncio ya implementado.
